#
# WHY THIS FILE EXISTS (BE3). Every F2 check on the consistent mass reads `M`
# through a quadratic form (`v^T M v`, `Phi^T M Phi`) or through an eigenproblem
# (`eigh(k, m)`). Not one reads `M . a`, and `M . a` is the only product inertia
# relief forms. The R541 sign defect lived through fifteen review rounds inside
# that gap: it is identically invisible in `a^T M a` and identically invisible in
# `M . a` for a rigid TRANSLATION, and it is 22% of the nodal load in `M . a` for
# a rigid ROTATION at the model builder's own L/D = 2 limit.
#
# The shapes below are the ones a check written by the hand that writes the
# check would not choose: the vacuous ones, the far-centre ones, the slender
# ones where the defect is real and below any engineering threshold, the
# non-rigid ones V4.2 never asks for, and the one where the DEFECTIVE matrix
# blows up so that a relative counter fires for arithmetic rather than for the
# sign it claims to detect.
#
# WHAT A PASSING SCAN MEANS. For each entry, build `M . a` from the shipped
# element and compare it against `integral_0^L N^T rho a(x) dx` with shape
# functions transcribed independently of `floatfea.element.beam`. The two are
# the same object by construction, so a passing scan means the comparison is at
# round-off on EVERY entry -- and, separately, that `ma_sign_rel` below is
# reproduced by the check's own counter at the entry's own operating point.
#
# A SCAN THAT PASSES ON ma08 ALONE HAS MEASURED NOTHING. `ma08` is a rigid
# translation and the defect is 2.7e-16 there: a counter registered on a
# translation is a counter that cannot fail. `ma12` is the complement -- a
# non-rigid field that is 29% wrong in the product and 2.7e-16 in the quadratic
# form -- so the blind subspace is `{c3 = 0}` and not merely the rigid one.
#
# Fields
#   section, L, L_over_D   the member; steel S355, E=2.1e11, nu=0.3, rho=7850
#   phi                    12 E I / (kappa G A L^2), shipped `shear_parameter`
#   a                      the nodal acceleration vector, in the xy bending
#                          plane DOF (v_A, rz_A, v_B, rz_B)
#   ma_sign_rel            max|M_def . a - M_cor . a| / max|M_cor . a|, where
#                          M_def carries R541's `+` and M_cor the shipped `-`.
#                          THIS IS THE COUNTER, and it is only a counter where
#                          it is large.
#   quad_sign_rel          the same defect seen through `a^T M a`. Round-off
#                          here is the measurement of F2's blindness.
#   f2_gate_catches        does any shipped F2 gate redden at this entry
#
