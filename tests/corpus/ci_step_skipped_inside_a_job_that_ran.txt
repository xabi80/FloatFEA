# nothing, and is named NOWHERE. The job-level notice "N job(s) SKIPPED, so
# unavailable rather than passing" does not fire for a step. The only trace a
# skipped step leaves in a published report is that the ladder's passed count is
# SMALLER, with the same `1 failed` beside it.
#

#   44149168617 (rungs 1,2,3,6)  ladder row  2143 passed, 1 failed, 0 skipped

# nothing interprets. FV1 assigns the whole of `tests/regression` to CI at the
# pushed sha, and `tests/regression/test_f6_deliverable_agrees_with_itself.py` is
# the only automated check that a published deliverable still regenerates.
