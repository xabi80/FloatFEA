## 1. What gets built

Per `PLAN.md` §6 F2, and no more:

- **Nodes** and the model container.
- **3D two-node Timoshenko beam element** with shear deformation.
- **End releases** (pinned ends and partial releases).
- **Rigid links** via multi-point constraints.
- **Springs** and **point masses**.
- **Sparse assembly** and a **direct linear solve**.
- **Consistent mass matrix**, needed by G2.4 and untouched by any static test.

Element mathematics carries a comment naming its reference — textbook and
equation number — so the formulation can be checked against a source rather than
re-derived, per `CLAUDE.md` § Style.

## 2. Why nothing blocks this

F2 depends on nothing upstream, which is why `PLAN.md` §8 nominates it as the
parallel track when F1 slips. Two things that *could* have blocked it are already
settled:

- **Ladder rungs 1 and 2 are wired into CI** with `needs:` enforcing dependency
  order, so adding a verification case is a file drop.
- **The member local-axis convention is decided, enforced and tested**
  (`docs/conventions.md` § Member local axes; `floatfea/model/local_axes.py`).
  Local *x* from A to B, explicit orientation node required, `local y = z × x`,
  with the degeneracy guard firing on vertical members rather than silently
  switching reference axis. Every element sign convention depends on that triad,
  and retrofitting it would have meant re-deriving every sign.

The first tolerance entry, `MEMBER_ORIENTATION_DEGENERACY`, already exists with
its gate reference and a test that fails if it is raised to admit a vertical
member.

## 3a. Reference provenance — the thing F1 says will break

**Rungs 1 and 2 are entirely comparisons against analytic references, and F1's
single hardest lesson was that comparisons fail through their references.**

Every one of the six refuted rounds on G1.6 was a reference defect, not a solver
defect:

| round | the reference was wrong because |
|---|---|
| calm-water reconstruction | it omitted a term the solver applied |
| trapezoid vs rectangular | it used the textbook rule; the solver did not |
| omitted `A_inf` | it was a different quantity wearing the same name |
| interpolation across a steep gap | it was built where the quantity varies 60% |

**A textbook cantilever formula is the same category of object.** `PL^3/3EI` is a
reference someone transcribed, for a beam theory that may not be the one the
element implements, under end conditions that may not be the ones the model
applies.

So **every rung 1-2 case declares, at the lock, what its reference is and how it
was obtained** — one of three, and the distinction is not cosmetic:

| provenance | what it can catch | how it fails |
|---|---|---|
| **cited closed form** | a solver that disagrees with the literature | transcription; a formula for adjacent end conditions or a different beam theory |
| **independent implementation** | formulation errors, since two codes rarely err alike | both inheriting the same textbook misreading |
| **constructed** (manufactured solution) | that the discretisation converges to *the governing equations* | cannot be adjacent-but-wrong; fails only if the derivation is wrong, and the derivation is checkable by substitution |

A case whose reference is "the value the solver produced when it looked right" is
a golden file, not a verification case, and must be labelled as one.

**This is the tenth guard applied before the fact:** a test can be fully capable
of failing and still point at the wrong claim. For rungs 1-2 the claim lives in
the reference, so the reference is what the lock must pin.

## 4. Ordering

The ladder is ordered by dependency, and F2 should be built the same way: **rung
1 before rung 2**. A patch-test failure makes every cantilever comparison
uninterpretable, so the assembly and transformation must be proven before any
accuracy number is believed.

## 5. Lock Q&A — SETTLED 2026-08-30

### Q2 — CONSISTENT mass. Decided, and not on the frequency band.

The frequency argument is real but secondary. The binding reason is **G3.1a**,
one milestone later: it reconciles the FE model's mass, CoG **and inertia tensor**
against the model-definition YAML. A lumped mass matrix discards or crudely
approximates **rotational inertia at nodes**, so lumping would fail a gate that is
already written, for a reason having nothing to do with F2.

Consistent also carries the Rayleigh-Ritz theorem, which is what makes the
one-sided band below meaningful. Cost is negligible at this scale.

**Pre-registered sign (AO4).** Computed free-free frequencies are **upper bounds**
on the exact ones — a theorem for a conforming displacement-based element, since
the discretisation is a Rayleigh-Ritz restriction to a subspace. G2.4's band is
therefore one-sided:

```
0 <= (f_computed - f_exact) / f_exact <= FREE_FREE_FREQUENCY
```

A computed frequency **below** the analytic value is a finding even while inside
a symmetric tolerance: it means the mass matrix, the boundary conditions, or the
reference is wrong, and refinement will not move it back.

### Q1b — Reference provenance, per case. V2.2 added, for kappa.

| case | provenance | why |
|---|---|---|
| **V1.1** rigid-body modes | constructed | an eigenvalue *ratio*; no external reference needed |
| **V1.2** patch test | constructed | a constant strain state is exact by construction |
| **V1.3** unit scaling | constructed | same problem, scaled units; self-referential by design |
| **V2.1** slender cantilever | **manufactured solution** + cited closed form | easiest to transcribe adjacent-but-wrong |
| **V2.2** stubby cantilever | **manufactured solution** + cited closed form | **two** transcription risks — see below |
| **V2.3** torsion | **manufactured solution** + cited closed form | `TL/GJ` with a section-dependent `J` |
| **V2.4** 3D coupling | independent implementation | no closed form; a second assembly path |
| **V2.5** free-free frequencies | cited closed form | analytic beam frequencies are unambiguous |
| **V2.6** releases / rigid links | constructed | constraint behaviour, not accuracy |

**V2.2 carries the subtle one: `kappa`.** The stubby cantilever has *two*
transcription risks, not one — the Timoshenko tip-deflection formula, **and the
shear correction factor inside it**. `kappa` is section-dependent and genuinely
source-dependent: roughly **0.5** for a thin-walled tube by the simple argument,
**~0.53** by Cowper at `nu = 0.3`, **0.886** for solid circular. Different
textbooks give different values for the same section.

> **The trap:** if the ELEMENT uses one `kappa` and the REFERENCE FORMULA uses
> another, the test compares two different beams and passes or fails for the wrong
> reason — while looking like a clean closed-form check.

**Pinned at lock:** `kappa`'s value, its source, and the requirement that element
and reference consume **the same constant from one place**. It goes in
`floatfea/sections.py` with its citation, never as a literal in either the element
or the test. This is the U2 family — *verify the reference* — in its most ordinary
disguise.

### Q3 — SUBDIVIDE; do not taper the element. The stated question dissolves.

The local-axis triad is **unaffected by taper**: local *x* is still A→B, and taper
varies section properties *along* the length, not the axis. So the question as
written has no content.

The real question is whether the **element** is tapered, and it should not be —
and the reason is a **verification** reason, not a convenience one:

> A tapered Timoshenko element has no simple closed form, its stiffness requires
> numerical integration, and **there is no textbook reference to verify it
> against** — which violates §3a's provenance requirement *by construction*.

Prismatic elements plus subdivision keeps every element verifiable and moves taper
into the model builder, where it becomes a **meshing decision with its own
convergence check** rather than an unverifiable formulation.

### Q4 — Assert determinism; do not assume it. And audit the CLASS.

Factorise twice, compare bit-identical. Pin the fill-reducing ordering explicitly
and single-thread the factorisation for verification runs, exactly as
`OMP_NUM_THREADS=1` does for the G1.5 baseline.

**This is the THIRD library-default nondeterminism to surface** — Hypothesis
seeding, BLAS thread count, now solver ordering. **Three is a class, not three
incidents.** Audited once, as a class, in `floatfea/determinism.py`: every library
whose defaults can vary a result across runs, versions or thread counts, pinned in
one place with one test. Cheaper than meeting the fourth the way the first three
were met.


#### AP3 — pinning `v0` does not make degenerate eigenvectors meaningful

The ARPACK pin makes G2.1 *reproducible*. It does not make its eigenvectors
*right*, and the distinction is not pedantic.

Within the **six-fold degenerate zero eigenvalue**, the eigenvectors are an
**arbitrary basis of the rigid-body subspace** — non-unique *in principle*, not
merely non-reproducible. Any orthogonal mixture of the six is an equally valid
answer. A test asserting particular mode shapes would be asserting a property the
mathematics does not confer, and would pass only because the seed happened to
produce that basis.

**So G2.1 asserts on the SUBSPACE, not on the vectors:**

* the six computed eigenvalues are zero to tolerance, relative to the first
  flexible mode — **eigenvalues assert directly**, they are unique;
* the six known rigid-body vectors (three translations, three rotations about the
  centroid) **project onto the computed basis with nothing lost** — i.e. the
  computed modes *span* the rigid-body space.

The second is the real content. It is invariant under any basis choice inside the
degenerate block, which is precisely why it is the assertable thing.

The `v0` pin still matters and sits underneath this: **without it, even the
eigenvalues of a near-degenerate cluster can shuffle between runs**, and a
subspace test on a shuffled cluster compares different modes each time.

### Q1 — Geometric stiffness: **INCLUDE**. Measured, not argued.

`artifacts/q1_brace_buckling.py`. Decision rule as locked: `P/P_E < 0.1` defer,
`> 0.2` include, between → undecided pending F3.

**Lead with the invariance, not the ratio (AP1).** For a strength-sized member,

```
P/P_E = (P/A) (K L / r)^2 / (pi^2 E) = sigma_allow * lambda^2 / (pi^2 E)
```

The axial load cancels against the area it sized, so **`P/P_E` does not depend on
the design moment at all.** The 150–300 MN·m uncertainty — which dominates every
other structural number in this project and which only the FE model can pin —
**cannot reach this decision**. That is a stronger statement than any single
ratio, and it is what makes the answer robust rather than lucky.

#### Correction: `sigma_allow` was wrong by 11.11% (AP1/AP2)

The first run used `f_y / 1.5 = 236.7 MPa`. **The project basis is `0.6 f_y =
213.0 MPa`** (`docs/milestones/F1.md` §8) — lower by exactly `(1/1.5)/0.6`, so
every ratio in the first run was 11.11% high.

The threshold moved the *unfavourable* way: `lambda` at `P/P_E = 0.2` is **44.1**,
not the 41.9 quoted, which **widens** the range of sections qualifying for
deferral. So the "not reachable by a real section" claim was re-checked against
44.1 rather than assumed to carry.

Both constants now come from **`floatfea/sections.py`** (AP2). `sigma_allow` had
appeared with two values in two documents — the exact failure the `kappa` pin was
built to prevent, arriving one constant over.

I wrote that the conclusion "is not delicate" because the margin was large. **At

#### AQ1 — the margin rests on an input nobody has specified

`lambda = L/r` and `r = 0.3477 D` at the class-3 wall, so

```
lambda = 2.88 * L/D
```

**`lambda` is set by the BRACING PANEL GEOMETRY.** Truss *depth* was named a free
variable at Q3. **Panel spacing and diagonal angle have never been named in any
document**, and they set `L` directly and linearly. The `L = 14.14 m` used
throughout comes from a 10 m depth at 45° — *both assumed*.

This is the same shape as the truss-depth finding, one level down: a number that
looked like an input is a consequence of a layout nobody has chosen.

**Named dependency of F3's re-check, alongside real sections: the bracing layout
— panel spacing and diagonal angle.**

#### AQ2 — but the margin does not need defending: the error is asymmetric

| wrong choice | cost |
|---|---|
| **defer** wrongly | **~28%** error on the moments in the **governing** members |
| **include** wrongly | a day on a standard, well-tested element formulation |

And amplification is already **1.25 at `P/P_E = 0.200` exactly** — the threshold
itself. So **there is no point inside the undecided band where deferral becomes
attractive**: even at the bottom of it, deferring accepts 11% on the governing
members to save a day.

```
P/P_E = 0.200  ->  amplification 1.250   (25% on governing-member moments)
P/P_E = 0.221  ->  amplification 1.284   (28%)
P/P_E = 0.443  ->  amplification 1.795   (80%)
```

**Therefore F3's re-check is a CONFIRMATION, not a decision point**, and the lock
records it as one. As first written, "re-check at F3" read as though the decision
could flip. **It cannot flip in the direction that would cost anything.**

For deferral to become defensible the re-check would have to find

```
P/P_E < 0.1  ->  lambda <= 31.2  ->  L/D <= 10.85  ->  L <= 9.51 m
                                                       (33% shorter than assumed)
```

— a bracing layout that makes geometric stiffness **pointless**, e.g. a 6.7 m
truss depth at 45° or much tighter panel spacing. That is a **large move**, not
one nudging `0.221` across `0.200`.

**CONDITIONAL, and re-checkable at F3 (AO4a).** Rests on placeholder sections, a

### The manufactured-solution derivation, carried from the skeleton

> Retained because it is a derivation obligation the detailed plan must
> discharge, not a question. The rest of the pre-lock question prose is
> superseded by the settled answers above.

**SETTLED (AO3): yes**, for V2.1 (cantilever) and V2.3 (torsion) — the cases whose
textbook forms are easiest to transcribe adjacent-but-wrong — weighting the
convergence-order argument above single-mesh agreement.

**Subtlety to settle in the derivation, not in implementation.** A Timoshenko beam
has **two coupled fields**: transverse displacement `w(x)` and cross-section
rotation `phi(x)`, independent by construction — that independence *is* shear
deformation. A manufactured solution must satisfy **both** governing equations
with consistent forcing:

```
distributed transverse load   q(x)  =  -d/dx [ kGA ( w' - phi ) ]
distributed moment            m(x)  =  -d/dx [ EI phi' ] - kGA ( w' - phi )
```

Manufacture only `w(x)` and derive only `q(x)`, and `phi` is **silently
constrained** by whatever relation the derivation assumed — usually the
Euler-Bernoulli `phi = w'`. The result looks like MMS, converges, and tests a
weaker claim than intended: it would not distinguish a Timoshenko element from an
Euler-Bernoulli one, which is the exact discrimination **G2.3** exists for.

Choose `w(x)` and `phi(x)` **independently** (so `w' - phi` is not identically
zero) and derive both `q(x)` and `m(x)`. Cheap in the derivation, expensive to
discover later. The lock records the chosen fields.

## 5a. Tolerance discipline takes its first real load here

`floatfea/tolerances.py` holds four entries. Every one is either structural
(`MEMBER_ORIENTATION_DEGENERACY`) or derived from a measurement with its
counter-case recorded (`DEAD_DOF_RELATIVE_FLOOR`,
`INTERPOLATED_REFERENCE_TOLERANCE_FLOOR`, `PANEL_RECONSTRUCTION_RESIDUAL`).

**F2 will add many, most attached to convergence and accuracy claims** — and it is
the first milestone where *"the test fails, widen the tolerance"* is a live
temptation with a plausible justification available every time. "Shear locking at
this aspect ratio" and "the mesh is not converged" are true statements that also
happen to excuse any number.

The mechanism is built and has not been under pressure: one file, gate-referenced
comments, no local literals, a written justification in the closure artifact for
any change. What F2 should add, because the existing entries suggest the pattern
works:

> **Every accuracy tolerance states its COUNTER-CASE — the magnitude of a defect
> it must still catch.**

`PANEL_RECONSTRUCTION_RESIDUAL` is the model: `1e-12`, three orders above the
measured residual and **seven below** the smallest deliberate defect. That gap is
what makes it defensible rather than fitted, and a reviewer can check it reading
only the comment.

A tolerance with a floor but no ceiling can always be widened one more order and
still look principled. One with a stated counter-case cannot.

**SETTLED (AO1): enforced, and the counter-case is a VALUE, not a sentence.**

Parsing comments for a counter-case would be satisfied by writing the
right-shaped sentence — a check that certifies prose exists. So the counter-case
stops being prose and becomes a paired entry:

```python
CANTILEVER_TIP_DEFLECTION         = 1e-9
CANTILEVER_TIP_DEFLECTION_COUNTER = 1e-6   # smallest defect that must fail
```

Three properties, and the third is the one that matters:

1. **Existence is mechanically checkable** — every accuracy `X` has an
   `X_COUNTER`, the same shape of check AL3 applied to closure evidence.
2. **It cannot be satisfied by a sentence**, because `X_COUNTER` is a number an
   executable test consumes.
3. **Widening `X` toward `X_COUNTER` eventually breaks the counter-test.**

The ceiling becomes an **execution result rather than a reviewer's judgement**.
This is not new machinery: it is AM1/AM2 one level down — the mutation pattern
that found G1.2 after two readings had cleared it.

`PANEL_RECONSTRUCTION_RESIDUAL_COUNTER = 1.0e-5` is already in place as the worked
example, measured from one perturbed panel of 10,560 rather than chosen.

**Binds on ACCURACY tolerances only (AO2).** `floatfea/tolerances.py` now declares
a **CLASS** per entry. A *structural* tolerance is a threshold on a condition and
fires by design — `MEMBER_ORIENTATION_DEGENERACY` fires on the platform's vertical
spars on purpose. Demanding a counter-case there would force an artificial number,
and **a rule applied where it does not fit gets weakened to accommodate.**
