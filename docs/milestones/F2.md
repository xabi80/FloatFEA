## 1. What gets built

Per `PLAN.md` §6 F2, and no more:

- **Nodes** and the model container.
- **3D two-node Timoshenko beam element** with shear deformation.
- **End releases** (pinned ends and partial releases).
- **Rigid links** via multi-point constraints.
- **Springs** and **point masses**.
- **Sparse assembly** and a **direct linear solve**.
- **Consistent mass matrix**, needed by G2.4 and untouched by any static test.

Element mathematics carries a comment naming its reference — textbook and
equation number — so the formulation can be checked against a source rather than
re-derived, per `CLAUDE.md` § Style.

## 2. Why nothing blocks this

F2 depends on nothing upstream, which is why `PLAN.md` §8 nominates it as the
parallel track when F1 slips. Two things that *could* have blocked it are already
settled:

- **Ladder rungs 1 and 2 are wired into CI** with `needs:` enforcing dependency
  order, so adding a verification case is a file drop.
- **The member local-axis convention is decided, enforced and tested**
  (`docs/conventions.md` § Member local axes; `floatfea/model/local_axes.py`).
  Local *x* from A to B, explicit orientation node required, `local y = z × x`,
  with the degeneracy guard firing on vertical members rather than silently
  switching reference axis. Every element sign convention depends on that triad,
  and retrofitting it would have meant re-deriving every sign.

The first tolerance entry, `MEMBER_ORIENTATION_DEGENERACY`, already exists with
its gate reference and a test that fails if it is raised to admit a vertical
member.

## 3. Gates

| gate | what it proves | ladder |
|---|---|---|
| **G2.1** | Six rigid-body modes at zero strain energy, tested as an eigenvalue *ratio* against the first flexible mode so it is mesh- and unit-independent | V1.1 |
| **G2.2** | Patch test — a constant strain state recovered exactly. Catches assembly, transformation and connectivity errors, which is why it sits below every accuracy comparison. | **G2.3** | Cantilever tip deflection against closed form, **including the shear term on a deliberately stubby beam** where Euler-Bernoulli mislabelled as Timoshenko would pass V2.1 and fail here | V2.1, V2.2 |
| **G2.4** | Free-free natural frequencies against analytic values — the only gate that exercises the mass matrix | V2.5 |
| **G2.5** | Unit scaling: the same physical problem in a scaled unit system produces correctly scaled results. Catches hardcoded constants that no single-reference comparison will | V1.3 |

Plus **V2.3** (torsion, `TL/GJ` on a circular hollow section), **V2.4**
(three-dimensional coupling, where axial/bending/torsion couple through the

element tests).

## 3a. Reference provenance — the thing F1 says will break

**Rungs 1 and 2 are entirely comparisons against analytic references, and F1's
single hardest lesson was that comparisons fail through their references.**

Every one of the six refuted rounds on G1.6 was a reference defect, not a solver
defect:

| round | the reference was wrong because |
|---|---|
| calm-water reconstruction | it omitted a term the solver applied |
| trapezoid vs rectangular | it used the textbook rule; the solver did not |
| omitted `A_inf` | it was a different quantity wearing the same name |
| interpolation across a steep gap | it was built where the quantity varies 60% |

**A textbook cantilever formula is the same category of object.** `PL^3/3EI` is a
reference someone transcribed, for a beam theory that may not be the one the
element implements, under end conditions that may not be the ones the model
applies.

So **every rung 1-2 case declares, at the lock, what its reference is and how it
was obtained** — one of three, and the distinction is not cosmetic:

| provenance | what it can catch | how it fails |
|---|---|---|
| **cited closed form** | a solver that disagrees with the literature | transcription; a formula for adjacent end conditions or a different beam theory |
| **independent implementation** | formulation errors, since two codes rarely err alike | both inheriting the same textbook misreading |
| **constructed** (manufactured solution) | that the discretisation converges to *the governing equations* | cannot be adjacent-but-wrong; fails only if the derivation is wrong, and the derivation is checkable by substitution |

A case whose reference is "the value the solver produced when it looked right" is
a golden file, not a verification case, and must be labelled as one.

**This is the tenth guard applied before the fact:** a test can be fully capable
of failing and still point at the wrong claim. For rungs 1-2 the claim lives in
the reference, so the reference is what the lock must pin.

## 4. Ordering

The ladder is ordered by dependency, and F2 should be built the same way: **rung
1 before rung 2**. A patch-test failure makes every cantilever comparison
uninterpretable, so the assembly and transformation must be proven before any
accuracy number is believed.

## 5. Lock Q&A — SETTLED 2026-08-30

### Q2 — CONSISTENT mass. Decided, and not on the frequency band.

The frequency argument is real but secondary. The binding reason is **G3.1a**,
one milestone later: it reconciles the FE model's mass, CoG **and inertia tensor**
against the model-definition YAML. A lumped mass matrix discards or crudely
approximates **rotational inertia at nodes**, so lumping would fail a gate that is
already written, for a reason having nothing to do with F2.

Consistent also carries the Rayleigh-Ritz theorem, which is what makes the
one-sided band below meaningful. Cost is negligible at this scale.

**Pre-registered sign (AO4).** Computed free-free frequencies are **upper bounds**
on the exact ones — a theorem for a conforming displacement-based element, since
the discretisation is a Rayleigh-Ritz restriction to a subspace. G2.4's band is
therefore one-sided:

```
0 <= (f_computed - f_exact) / f_exact <= FREE_FREE_FREQUENCY
```

A computed frequency **below** the analytic value is a finding even while inside
a symmetric tolerance: it means the mass matrix, the boundary conditions, or the
reference is wrong, and refinement will not move it back.

### Q1b — Reference provenance, per case. V2.2 added, for kappa.

| case | provenance | why |
|---|---|---|
| **V1.1** rigid-body modes | constructed | an eigenvalue *ratio*; no external reference needed |
| **V1.2** patch test | constructed | a constant strain state is exact by construction |
| **V1.3** unit scaling | constructed | same problem, scaled units; self-referential by design |
| **V2.1** slender cantilever | **manufactured solution** + cited closed form | easiest to transcribe adjacent-but-wrong |
| **V2.2** stubby cantilever | **manufactured solution** + cited closed form | **two** transcription risks — see below |
| **V2.3** torsion | **manufactured solution** + cited closed form | `TL/GJ` with a section-dependent `J` |
| **V2.4** 3D coupling | independent implementation | no closed form; a second assembly path |
| **V2.5** free-free frequencies | cited closed form | analytic beam frequencies are unambiguous |
| **V2.6** releases / rigid links | constructed | constraint behaviour, not accuracy |

**V2.2 carries the subtle one: `kappa`.** The stubby cantilever has *two*
transcription risks, not one — the Timoshenko tip-deflection formula, **and the
shear correction factor inside it**. `kappa` is section-dependent and genuinely
source-dependent: roughly **0.5** for a thin-walled tube by the simple argument,
**~0.53** by Cowper at `nu = 0.3`, **0.886** for solid circular. Different
textbooks give different values for the same section.

> **The trap:** if the ELEMENT uses one `kappa` and the REFERENCE FORMULA uses
> another, the test compares two different beams and passes or fails for the wrong
> reason — while looking like a clean closed-form check.

**Pinned at lock:** `kappa`'s value, its source, and the requirement that element
and reference consume **the same constant from one place**. It goes in
`floatfea/sections.py` with its citation, never as a literal in either the element
or the test. This is the U2 family — *verify the reference* — in its most ordinary
disguise.

### Q3 — SUBDIVIDE; do not taper the element. The stated question dissolves.

The local-axis triad is **unaffected by taper**: local *x* is still A→B, and taper
varies section properties *along* the length, not the axis. So the question as
written has no content.

The real question is whether the **element** is tapered, and it should not be —
and the reason is a **verification** reason, not a convenience one:

> A tapered Timoshenko element has no simple closed form, its stiffness requires
> numerical integration, and **there is no textbook reference to verify it
> against** — which violates §3a's provenance requirement *by construction*.

Prismatic elements plus subdivision keeps every element verifiable and moves taper
into the model builder, where it becomes a **meshing decision with its own
convergence check** rather than an unverifiable formulation.

### Q4 — Assert determinism; do not assume it. And audit the CLASS.

Factorise twice, compare bit-identical. Pin the fill-reducing ordering explicitly
and single-thread the factorisation for verification runs, exactly as
`OMP_NUM_THREADS=1` does for the G1.5 baseline.

**This is the THIRD library-default nondeterminism to surface** — Hypothesis
seeding, BLAS thread count, now solver ordering. **Three is a class, not three
incidents.** Audited once, as a class, in `floatfea/determinism.py`: every library
whose defaults can vary a result across runs, versions or thread counts, pinned in
one place with one test. Cheaper than meeting the fourth the way the first three
were met.


#### AP3 — pinning `v0` does not make degenerate eigenvectors meaningful

The ARPACK pin makes G2.1 *reproducible*. It does not make its eigenvectors
*right*, and the distinction is not pedantic.

Within the **six-fold degenerate zero eigenvalue**, the eigenvectors are an
**arbitrary basis of the rigid-body subspace** — non-unique *in principle*, not
merely non-reproducible. Any orthogonal mixture of the six is an equally valid
answer. A test asserting particular mode shapes would be asserting a property the
mathematics does not confer, and would pass only because the seed happened to
produce that basis.

**So G2.1 asserts on the SUBSPACE, not on the vectors:**

* the six computed eigenvalues are zero to tolerance, relative to the first
  flexible mode — **eigenvalues assert directly**, they are unique;
* the six known rigid-body vectors (three translations, three rotations about the
  centroid) **project onto the computed basis with nothing lost** — i.e. the
  computed modes *span* the rigid-body space.

The second is the real content. It is invariant under any basis choice inside the
degenerate block, which is precisely why it is the assertable thing.

The `v0` pin still matters and sits underneath this: **without it, even the
eigenvalues of a near-degenerate cluster can shuffle between runs**, and a
subspace test on a shuffled cluster compares different modes each time.

### Q1 — Geometric stiffness: **INCLUDE**. Measured, not argued.

`artifacts/q1_brace_buckling.py`. Decision rule as locked: `P/P_E < 0.1` defer,
`> 0.2` include, between → undecided pending F3.

**Lead with the invariance, not the ratio (AP1).** For a strength-sized member,

```
P/P_E = (P/A) (K L / r)^2 / (pi^2 E) = sigma_allow * lambda^2 / (pi^2 E)
```

The axial load cancels against the area it sized, so **`P/P_E` does not depend on
the design moment at all.** The 150–300 MN·m uncertainty — which dominates every
other structural number in this project and which only the FE model can pin —
**cannot reach this decision**. That is a stronger statement than any single
ratio, and it is what makes the answer robust rather than lucky.

#### AQ1 — the margin rests on an input nobody has specified

#### AQ2 — but the margin does not need defending: the error is asymmetric

| wrong choice | cost |
|---|---|
| **defer** wrongly | **~28%** error on the moments in the **governing** members |

And amplification is already **1.25 at `P/P_E = 0.200` exactly** — the threshold

### The manufactured-solution derivation, carried from the skeleton

> Retained because it is a derivation obligation the detailed plan must
> discharge, not a question. The rest of the pre-lock question prose is
> superseded by the settled answers above.

**SETTLED (AO3): yes**, for V2.1 (cantilever) and V2.3 (torsion) — the cases whose
textbook forms are easiest to transcribe adjacent-but-wrong — weighting the
convergence-order argument above single-mesh agreement.

**Subtlety to settle in the derivation, not in implementation.** A Timoshenko beam
has **two coupled fields**: transverse displacement `w(x)` and cross-section
rotation `phi(x)`, independent by construction — that independence *is* shear
deformation. A manufactured solution must satisfy **both** governing equations
with consistent forcing:

```
distributed transverse load   q(x)  =  -d/dx [ kGA ( w' - phi ) ]
distributed moment            m(x)  =  -d/dx [ EI phi' ] - kGA ( w' - phi )
```

Manufacture only `w(x)` and derive only `q(x)`, and `phi` is **silently
constrained** by whatever relation the derivation assumed — usually the
Euler-Bernoulli `phi = w'`. The result looks like MMS, converges, and tests a
weaker claim than intended: it would not distinguish a Timoshenko element from an
Euler-Bernoulli one, which is the exact discrimination **G2.3** exists for.

Choose `w(x)` and `phi(x)` **independently** (so `w' - phi` is not identically
zero) and derive both `q(x)` and `m(x)`. Cheap in the derivation, expensive to
discover later. The lock records the chosen fields.

## 5a. Tolerance discipline takes its first real load here

`floatfea/tolerances.py` holds four entries. Every one is either structural
(`MEMBER_ORIENTATION_DEGENERACY`) or derived from a measurement with its
counter-case recorded (`DEAD_DOF_RELATIVE_FLOOR`,
`INTERPOLATED_REFERENCE_TOLERANCE_FLOOR`, `PANEL_RECONSTRUCTION_RESIDUAL`).

**F2 will add many, most attached to convergence and accuracy claims** — and it is
the first milestone where *"the test fails, widen the tolerance"* is a live
temptation with a plausible justification available every time. "Shear locking at
this aspect ratio" and "the mesh is not converged" are true statements that also
happen to excuse any number.

The mechanism is built and has not been under pressure: one file, gate-referenced
comments, no local literals, a written justification in the closure artifact for
any change. What F2 should add, because the existing entries suggest the pattern
works:

> **Every accuracy tolerance states its COUNTER-CASE — the magnitude of a defect
> it must still catch.**

`PANEL_RECONSTRUCTION_RESIDUAL` is the model: `1e-12`, three orders above the
measured residual and **seven below** the smallest deliberate defect. That gap is
what makes it defensible rather than fitted, and a reviewer can check it reading
only the comment.

A tolerance with a floor but no ceiling can always be widened one more order and
still look principled. One with a stated counter-case cannot.

**SETTLED (AO1): enforced, and the counter-case is a VALUE, not a sentence.**

Parsing comments for a counter-case would be satisfied by writing the
right-shaped sentence — a check that certifies prose exists. So the counter-case
stops being prose and becomes a paired entry:

```python
CANTILEVER_TIP_DEFLECTION         = 1e-9
CANTILEVER_TIP_DEFLECTION_COUNTER = 1e-6   # smallest defect that must fail
```

Three properties, and the third is the one that matters:

1. **Existence is mechanically checkable** — every accuracy `X` has an
   `X_COUNTER`, the same shape of check AL3 applied to closure evidence.
2. **It cannot be satisfied by a sentence**, because `X_COUNTER` is a number an
   executable test consumes.
3. **Widening `X` toward `X_COUNTER` eventually breaks the counter-test.**

The ceiling becomes an **execution result rather than a reviewer's judgement**.
This is not new machinery: it is AM1/AM2 one level down — the mutation pattern
that found G1.2 after two readings had cleared it.

`PANEL_RECONSTRUCTION_RESIDUAL_COUNTER = 1.0e-5` is already in place as the worked
example, measured from one perturbed panel of 10,560 rather than chosen.

**Binds on ACCURACY tolerances only (AO2).** `floatfea/tolerances.py` now declares
a **CLASS** per entry. A *structural* tolerance is a threshold on a condition and
fires by design — `MEMBER_ORIENTATION_DEGENERACY` fires on the platform's vertical
spars on purpose. Demanding a counter-case there would force an artificial number,
and **a rule applied where it does not fit gets weakened to accommodate.**

## 6. Not in F2

Load mapping (F4), inertia relief (F4), the platform model itself (F3), and

and textbook cases with **no hydrodynamics anywhere in the loop**, which is the

## D1. Module layout

```
floatfea/
  basis.py             EXISTS -- the project basis: E/nu/G/rho, sigma_allow,
                       CHS class limits, exact tube properties, kappa(shape, nu)
  determinism.py       EXISTS -- library-default pins (Q4)
  tolerances.py        EXISTS -- gains F2's accuracy entries, each with a _COUNTER
  model/
    local_axes.py      EXISTS -- member triad, degeneracy guard
    nodes.py           NEW -- Node, DOF numbering, the model container
    material.py        NEW -- Material, Section containers; consume basis.py,
                       define nothing, and store NO kappa (AS1)
  element/
    beam.py            NEW -- 2-node Timoshenko, 12 DOF: k_e, m_e, k_g
    releases.py        NEW -- end-release condensation
    constraints.py     NEW -- rigid links (master-slave), springs, point masses
  assemble/
    system.py          NEW -- sparse assembly, boundary conditions
    solve.py           NEW -- direct factorisation, eigen-solve
```

**`material.py` defines no constants.** It holds the *containers*; every value
comes from `basis.py`.

**`kappa` is COMPUTED, never STORED (AS1).** It depends on **both** section
geometry and Poisson's ratio — 0.5306 thin tube, 0.8864 solid circular, both
varying with `nu` — so it belongs to **neither container alone**. It is obtained
by calling `basis.kappa(shape, nu)`; it is never a field on `Material`, never a
field on `Section`, never a default argument.

This is stronger than the single-source rule and it **outlives the reason for
it**: a stored `kappa` is wrong as soon as the section or `nu` changes, so the
physics forbids the field even for someone who has forgotten why duplication is
banned. `Section` carries a **shape**, not a coefficient, and an unknown shape
**raises** rather than defaulting — a silent fallback to a tube value on a
non-tube section is the two-different-beams failure in its purest form.

**Named `basis.py`, not `sections.py` (AS2).** The old name described half the
contents, and a file called `sections.py` holding `E` and `sigma_allow` will
eventually attract a `materials.py` with its own `E`. That is the duplication this
module prevents, arriving through **naming** rather than carelessness.

## D3. Element formulation, with references

Every matrix carries a comment naming textbook and equation, per `CLAUDE.md`
§ Style. Primary reference:

> Przemieniecki, J.S., *Theory of Matrix Structural Analysis*, McGraw-Hill 1968.
> Reprint Dover 1985.

Cross-checked against Cook, Malkus, Plesha & Witt, *Concepts and Applications of
Finite Element Analysis*, 4th ed., Wiley 2002.

**Shear-flexible bending.** With

```
Phi = 12 EI / (kappa G A L^2)
```

the exact two-node Timoshenko stiffness in one bending plane is

```
              EI          [  12      6L     -12      6L    ]
k_b = ------------------- [  6L  (4+Phi)L^2  -6L  (2-Phi)L^2]
       L^3 (1 + Phi)      [ -12     -6L      12     -6L    ]
                          [  6L  (2-Phi)L^2  -6L  (4+Phi)L^2]
```

Przemieniecki §5.6. **`Phi -> 0` recovers Euler-Bernoulli exactly**, which is the
first unit test on the element and the thing V2.2 exists to distinguish.

`kappa` comes from `sections.kappa_thin_tube()` — **never a literal, never a
default argument.** Axial `EA/L`, torsion `GJ/L`, both Przemieniecki §5.

**Consistent mass** including rotary inertia: Przemieniecki §11.4. Decided at Q2,
and the binding reason is G3.1a's inertia-tensor reconciliation, not G2.4.

**Geometric stiffness**, cubic interpolation, Przemieniecki §12.3:

```
        P    [  36    3L   -36    3L  ]
k_g = ------ [  3L   4L^2  -3L   -L^2 ]
       30 L  [ -36   -3L    36   -3L  ]
             [  3L   -L^2  -3L   4L^2 ]
```

`P` positive in tension. This is the cubic-interpolation form, **not** the
consistent geometric stiffness for a shear-flexible beam.

**That is a NON-ISSUE with a proof, not a limitation (AS3), and it is recorded
that way deliberately — a documented limitation invites revisiting; a documented
non-issue does not.**

**Stated as a BOUND, not an identity (AT1).** What is proved is
`Phi * (P/P_E) = 12 sigma_actual / (kappa G pi^2)` — an identity at whatever
stress a member happens to carry, and so on its own a statement about the
strength-sized braces and nothing else. The useful form is the inequality: any
member passing its strength check has `sigma_actual <= sigma_allow`, therefore

```
Phi * (P/P_E)  <=  12 sigma_allow / (kappa G pi^2)
```

Under-stressed members satisfy it with room to spare, so **the bound covers the
whole model rather than the sized subset** — which is what the self-limiting
argument for the cubic `k_g` actually needs.

It scales with `sigma_allow / G` and survives every structural steel:

| material | `sigma_allow` at `0.6 f_y` | bound |
|---|---|---|
| S235 | 141.0 MPa | **0.400%** |
| S355 | 213.0 MPa | **0.604%** |
| S460 | 276.0 MPa | **0.783%** |

If it ever breaks it will be **the material pair or the allowable basis**, never
the geometry. **Compute it with `basis.shear_geometric_bound()`; do not leave
0.604% standing as a bare constant** — someone changes the allowable basis in
three months and the quoted number silently stops being a bound.

The refinement matters in proportion to `Phi`; geometric stiffness itself matters
in proportion to `P/P_E`. For any section `I = A r^2`, so both reduce to functions
of slenderness alone — and their **product is invariant**:

```
Phi   = (12 E / (kappa G)) / lambda^2
P/P_E = (sigma_allow / (pi^2 E)) * lambda^2

Phi * (P/P_E) = 12 sigma_allow / (kappa G pi^2) = 0.604%
```

`lambda` cancels **identically**. Independent of slenderness, of the section, and
of the load:

```
 lambda      Phi    P/P_E   product
   20.0   0.1470   0.0411  0.006043     k_g negligible
   46.4   0.0273   0.2213  0.006043     the governing brace
   70.0   0.0120   0.5036  0.006043     k_g matters, Phi tiny
  100.0   0.0059   1.0277  0.006043
```

**The two effects are anti-correlated by construction.** A member slender enough
for geometric stiffness to matter has negligible shear flexibility; one stocky
enough for shear flexibility to matter has negligible `P/P_E`. **The correction
term has nowhere to be large.**

At the governing brace that bounds the refinement at `0.604%` of a 28%
amplification — **0.17% on the moment**. Asserted in
`tests/verification/rung3/test_basis_constants.py`, against both the closed form
and a direct evaluation at several slendernesses: if the invariance held only
approximately, this deferral would be a judgement rather than a proof.

## D4. Verification cases — reference provenance per §3a and Q1b

### Manufactured solutions: BOTH fields forced (Q1a)

The derivation obligation from the lock, discharged concretely. Choose

```
w(x)   = a3 x^3 + a2 x^2 + a1 x + a0        transverse displacement
phi(x) = b2 x^2 + b1 x + b0                 cross-section rotation
```

with `b` chosen so `w' - phi` is **not identically zero** — that difference *is*
the shear strain, and a manufactured solution with `phi = w'` silently degenerates
to Euler-Bernoulli and cannot distinguish the two elements. Forcing:

```
q(x) = -d/dx [ kappa G A ( w' - phi ) ]
m(x) = -d/dx [ EI phi' ] - kappa G A ( w' - phi )
```

Applied as consistent nodal loads. **Both `q` and `m` are applied**; omitting `m`
is the failure mode the lock names.

`w` cubic and `phi` quadratic sit **above** the element's exactness for a
distributed load, so the discretisation error is non-zero and the **observed
convergence order** is the assertable quantity — `O(h^2)` in displacement for this
element. A formulation error typically still agrees at one mesh and degrades the
rate, which is why the rate is the stronger instrument.

### R7 — the gate's scope is not a results column

`e1ea251` replaced this gate's statement of *what it proves* with its *outcome*:
"**PASS**: `2.88e-17 .. 4.21e-15`". Recording a result is legitimate. Overwriting

the work they judge.

### AV4 — the patch test has FOUR states, and all four must be EXACT

For a beam the constant-strain states are:

1. **constant axial strain**
2. **constant curvature** (in each bending plane)
3. **constant twist**
4. **constant shear**, with its accompanying *linear* moment

All four are exact for this element, and the patch test asserts exactness with
the same ULP discipline as AU4 — **not convergence**.

> **A Timoshenko element that reproduces constant curvature only in the limit is
> not passing the patch test. It is passing a convergence test wearing its
> clothes.**

The distinction matters because the two look identical on a refinement plot and
only one of them is the gate. State 4 is the one most easily got wrong: a
formulation that handles constant curvature exactly can still fail constant shear,
and it is the state that exercises the `Phi` terms rather than cancelling them.

### AS4 — V2.2's primary assertion is at ONE ELEMENT, not a mesh sweep

The exact Timoshenko stiffness is **nodally exact** for constant section and
constant load: it is the exact solution of the governing ODEs, so an end-loaded
cantilever must match the closed form with **a single element, to round-off**.

**So V2.2 asserts at `N = 1` first.** The mesh sweep is secondary — a
consistency check, not the gate.

This is pre-registered as *nodally exact* rather than *locking-free* because it
removes the mesh reflex **categorically**:

> **If `N = 1` is wrong, refinement is the wrong response — there is nothing for
> refinement to fix.**

"Locking-free" still invites "try a finer mesh"; "nodally exact at N = 1" makes
refinement obviously beside the point. The distributed-load MMS cases *do* need a
sweep, because there the element is not nodally exact and the convergence **order**
is the assertable quantity — but the end-loaded case is not one of them.

**V2.2 is where `kappa` bites.** Element and reference formula consume
`sections.kappa_thin_tube()`. A test that hardcodes `0.5` while the element uses
Cowper's `0.5305` compares two different beams — 6% apart, comfortably inside any
plausible tolerance, and invisible.

### `RESULTANT_EXACTNESS` — added at step 4, and why G2.2 needed a second quantity

**Justification of record for the entry** (`CLAUDE.md` § Tolerances: a value's
reason lives in the milestone artifact, not only in the comment beside it).

G2.2 asserted two things: the nodal field against the exact field, and
`‖Ku − f‖/‖f‖` against the *same* ceiling. The second was measured at step 4's
fifth review and **does not move under the defect the first one catches**:

```
state         clean      1e-3 defect   2x defect   (displacement err at 2x)
axial       5.931e-16     4.700e-16    3.356e-16      6.46e-02
curvature   1.056e-15     1.258e-15    1.490e-15      6.37e-02
shear       1.729e-15     1.418e-15    1.162e-15      6.89e-02
```

For two of three states it moves *down*. A linear-solve residual measures the
factorisation, not the element, and comparing it against a displacement-field
exactness tolerance made the line unfalsifiable in both directions at once.

**What replaces it** is the quantity a patch test should have carried from the
start: the element's **recovered end forces** against the analytic resultants of
the state — `EA·ε`, `EI·κ` in each bending plane, `GJ·φ′`, and for state 4 the
constant shear `P` with its linear moment `P(L−x)`. Statics and section
properties, on both sides independent of the solve's residual.

Measured, worst over six states × two orientations, at a 1e-6 single-element
stiffness defect:

```
channel        clean (S=1)   at 1e-6 defect   at 2x defect
displacement     1.25e-14       1.08e-07         6.4e-02
resultants       3.92e-13       6.90e-07         4.1e-01
```

The resultant channel is **6.4× the more sensitive**, which is why it is added
beside the field check rather than instead of it. Its ceiling is a separate
entry because it is a different quantity: forming `k u` differentiates the field
and loses two to three digits to cancellation — measured `1.19e-13` on the
*exact* field, where no solve is involved at all.

`RESULTANT_EXACTNESS = 1e-9` is set from the worst measurement over the scales
the shipped test runs (`S = 1e-3, 1, 1e3`): `4.558e-11`, 22× below the ceiling.
`RESULTANT_EXACTNESS_COUNTER = 6.8e-7` is set just under the smallest per-state
response to that 1e-6 defect (`6.898e-07`), so every state must catch it.

### V2.2's tolerance provenance, fixed now while the measurement is fresh (AU4)

**Nodal exactness is EXACT, so V2.2's tolerance is a ULP multiple and nothing
else.** Measured at step 2 on a one-element cantilever, both load cases, both
`Phi` values:

```
slender  Phi = 0.0112   end force 1.11e-16   end moment 1.11e-16
stubby   Phi = 0.7769   end force 0.00e+00   end moment 3.33e-16
```

Four values, three of them at or below 1 ULP of double precision. **The tolerance
is justified by these four numbers, not chosen for comfort**, and it is written
down now precisely so that step 8 cannot arrive at a round engineering number
instead.

The counter-case is the demonstration that an **Euler-Bernoulli element
mislabelled as Timoshenko fails by 16.3%** — the shear share `(Phi/4)/(1+Phi/4)`
at the stubby case, asserted in `tests/unit/test_cantilever_closed_form.py` so
that the discriminating power of the case cannot quietly erode.

**Why a round number would be wrong here, precisely.** A tolerance of `1e-9` would
still catch the 16% case. What it would pass is a formulation wrong at the `1e-10`
level — and *nobody would then investigate it*, because it sits inside a declared
tolerance. **The whole content of an exactness claim is that there is nothing
between exact and wrong**: a discrepancy at `1e-10` is not a small error in a
nodally exact element, it is evidence the element is not the one documented.

**The counter-cases are the interesting column.** Each is a defect that a
plausible implementation actually makes, so the ceiling is bounded by something
real rather than by a round number. `CANTILEVER_TIP_DEFLECTION`'s in particular
must be tighter than the 6% `kappa` gap, or V2.2 cannot do the job Q1b assigned it.

## D7. Deliberate limitations, recorded now rather than discovered later

1. **Geometric stiffness is the cubic-interpolation form**, not the shear-flexible
   consistent one. Verifiable against a closed-form strut; the refinement is not.
2. **Rigid links by master-slave elimination**, not Lagrange multipliers — exact,
   no extra DOF, and it keeps the system positive definite for the eigen-solve.
   Lagrange would be more general and is not needed by F3's geometry.
3. **Prismatic elements only** (Q3). Taper enters through subdivision in the model
   builder, with its own convergence check.
4. **No shear centre / warping.** Circular hollow sections only, where shear
   centre and centroid coincide. `docs/verification/README.md` already notes this
   must be revisited if a non-circular section is ever introduced.
5. **G2.2's ceiling is validated over a slenderness range, and F3 inherits the
   obligation to stay inside it (R43).** `PATCH_TEST_EXACTNESS = 1e-12` is
   measured at the gate's posed geometry — tube 0.6/0.012, element lengths
   0.79–3.27 m, longest-element `L/r = 15.7`, worst error `1.25e-14`. Measured,
   the ceiling is breached at `L/r ≈ 119` (bisected; `1.76e-12` at `L/r = 94.4`).
   The platform's governing brace is at `λ = 46.4` per §5's corrected Q1 table —
   `1.57e-13`, 6× of margin — so **no F2 gate is affected**.

   **F3's named dependency:** when the real model is built, assert that every
   member's element slenderness lies inside the range G2.2's tolerance was
   validated over, and fail the build if it does not. A member at `L/r = 150`
   would be analysed under a rung-1 gate that does not hold for it, and nothing
   downstream would say so. The assertion belongs with the model builder, not
   here, because it is a property of the model rather than of the element.

## D8. What could go wrong

**Shear locking.** The element is **nodally exact** (AS4), so on the end-loaded
cantilever `N = 1` must match the closed form to round-off. **If it does not, the
formulation is wrong and refinement cannot fix it** — there is nothing for
refinement to fix. Pre-registering it this way, rather than as "locking-free",
removes the mesh reflex categorically instead of arguing against it.

**AS5 — if discrimination is ever needed, the axis is SLENDERNESS, not mesh.**
Should `N = 1` fail and the cause be genuinely unclear, the candidates are locking
and a wrong coefficient, and they **diverge along `L/h`**:

| candidate | behaviour as `L/h` grows at fixed mesh |
|---|---|
| **shear locking** | error **grows** |
| **wrong coefficient** (`kappa`, `Phi`, a term) | error **does not move** |

Refining the mesh improves *both* and separates neither. This is the same shape as
the V1 frequency discriminator that broke the G1.6 deadlock: **find the axis along
which the candidates diverge, not the one along which both improve.**

**MMS derivation error.** The forcing is derived by hand; an error there makes the
test converge to the wrong thing at the right rate. Mitigation: substitute the
manufactured fields back into the governing equations symbolically and assert the
residual is zero before using them. **The derivation is checkable by substitution
— that is the property that makes MMS a constructed reference rather than a
transcribed one, and it should be exercised, not assumed.**

**`kappa` divergence.** Guarded by `sections.py` and its tests.

## D8a. A note on the pattern

**The load cancelled in Q1; `lambda` cancels here.** Both came from the same move
— asking what value of the uncertain input would change the answer, rather than
how confident we are in the value we have (fifteenth guard).

And in both cases **the cancellation is what converts a case-by-case check into a
model-wide one**: Q1's decision holds for any design moment, and the `k_g` bound
holds for any member in the model rather than for the braces that were sized. That
is the payoff worth looking for — not a tighter number, but a claim that no longer
needs re-checking per case.
