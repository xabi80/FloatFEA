  Full entry in `FZ.md`.
- **SR-8** — the same defect one file type over: `(OSError, json.JSONDecodeError)` at
  **four** sites, none catching `UnicodeDecodeError`, which a non-UTF-8 sidecar raises

  the next reader; censused over the whole module rather than over the sites the repair
